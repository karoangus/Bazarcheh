# 🕸️ بازارچه دارک وب — نسخه ۱۳.۰

بازی استراتژی خرید و فروش کالا به سبک بازارچه — با سه حالت بازی:

| حالت | توضیح |
|------|-------|
| 🎮 آفلاین | بازی تکی، بدون اینترنت (سیو محلی) |
| 🤖 با بات | رقابت با بات‌های هوشمند در چهار سطح |
| 🌐 آنلاین | دوئل واقعی با بازیکن‌های دیگه (رندوم یا دوستانه) روی Supabase |

## چیدمان صفحهٔ بازی

در دسکتاپ صفحهٔ بازی فضای پنجره را پر می‌کند و پنل‌های طولانی مستقل اسکرول می‌شوند. در موبایل، نوار پایین شامل دکمه‌های اصلی و «وضعیت» است؛ اطلاعات مالی، رتبه‌بندی و حریف آنلاین در زبانهٔ وضعیت قرار دارند. در صفحه‌های کوتاه یا محتوای طولانی، خود پنل بازی قابل اسکرول است تا هیچ کنترلی پنهان نشود.

برای تست اختیاری رابط با `playwright-core` و Chromium، سرور استاتیک را اجرا کنید و سپس `CHROMIUM_PATH=/path/to/chromium node tests/responsive-layout.test.cjs` را بزنید.

## رفع خطای شروع بازی آنلاین

دو Edge Function آنلاین هنگام اجرا با `BOOT_ERROR` از کار می‌افتادند. مچ‌میکینگ و هماهنگی نوبت اکنون از RPCهای تراکنشی Postgres در `supabase/migrations/20261031_multiplayer_rpc.sql` استفاده می‌کنند؛ مایگریشن باید پیش از انتشار کلاینت روی پروژه اجرا شود. احراز هویت و دوستان همچنان از Edge Functionهای قبلی استفاده می‌کنند. برای دریافت نسخه جدید، صفحه یا وب‌اپ نصب‌شده را پس از انتشار تازه کنید.

تست کلاینت: `node tests/multiplayer-client.test.cjs`؛ تست دیتابیس: `tests/multiplayer-rpc.sql` فقط در دیتابیس آزمایشی ایزوله اجرا شود.

## ✨ چه چیزهایی در نسخه ۱۳ عوض شد؟

###  مولتی‌پلیر — باگ‌گیری اساسی
- **مچ‌میکینگ اتمی**: RPC دیتابیس `bazaar_match_join` صف و پیوستن به مچ را در تراکنش هماهنگ می‌کند.
- **هماهنگی نوبت اتمی**: RPC دیتابیس `bazaar_match_turn` اکشن‌های `ready / check / sync / finish` را با قفل ردیف اجرا می‌کند.
- **برنده روی سرور محاسبه می‌شه**: سود = پول نقد + ارزش انبار − سرمایه اولیه − بدهی (فرمول یکسان برای هر دو طرف؛ قبلاً یک جا بدون ارزش انبار محاسبه می‌شد و نتایج ضدونقیض بود).
- **رویدادهای تصادفی مشترک روی سرور رول می‌شن**: قبلاً هر کلاینت جدا رول می‌کرد و قیمت‌های دو بازیکن از هم واگرا می‌شد!
- **وضعیت بازیکن با اکشن `sync` اتمی merge می‌شه**: قبلاً کل `game_state` بازنویسی می‌شد و می‌تونست وضعیت حریف یا پیشروی روز رو بپرونه (lost-update).
- **تشخیص آفلاین حریف + پیروزی خودکار**: heartbeat هر ۵ ثانیه؛ اگه حریف ~۹۰ ثانیه نباشه، دکمه «پیروزی خودکار» فعال می‌شه (سرور هم راستی‌آزمایی می‌کنه).
- **ریزامی بازی نیمه‌تمام**: تب بسته شد؟ قطعی اینترنت؟ دفعه بعد که وارد شی، کارت «ادامه بازی» منتظرته. `pagehide` هم تلاش می‌کند آخرین وضعیت را با درخواست `keepalive` ذخیره کند.
- **ترک بازی = باختِ ثبت‌شده**: دکمه 🏳️ ترک؛ حریف نتیجه واقعی می‌گیره نه بن‌بست ابدی.
- **پاکسازی صف‌های انتظار کهنه** (۱۵ دقیقه) برای جلوگیری از باقی ماندن مچ‌های رهاشده.
- **رندر هوشمند**: پولینگ ۳ ثانیه‌ای حریف دیگه inputهای بازِ معامله رو ریست نمی‌کنه و فقط وقتی داده عوض شده رندر می‌کنه.

### 🗄️ سوپابیس
- پروژه restore شد و جدول‌ها/RLS/ایندکس‌ها تعمیر شدن (سیاست DELETE روی `matches` نبود!).
- مایگریشن: `supabase/migrations/20261030_multiplayer_fixes.sql`
- سورس توابع لبه نسخه‌کنترل شدن: `supabase/functions/*`

### 📲 وب‌اپ قابل نصب (PWA)
- `manifest.webmanifest` + `sw.js` + آیکون‌ها → نصب روی گوشی/دسکتاپ مثل یک اپ واقعی.
- حالت آفلاین و بات **بدون اینترنت** هم کار می‌کنن (پوسته اپ کش می‌شه).
- supabase-js و فونت وزیرمتن **داخل ریپو vendor شدن** — بدون وابستگی به CDN (سریع‌تر و قابل‌اعتمادتر، مخصوصاً پشت فیلترشکن‌های CDN).

### 🎨 تحول رابط کاربری
- تم «Bazaar Noir»: پنل‌های شیشه‌ای، گرادیان‌های طلایی، انیمیشن‌های نرم، هدر چسبان.
- سه رنگ تأکید (نارنجی/سبز/آبی) + تم تاریک/روشن + حالت پرفورمنس.
- چیدمان واکنش‌گرا: سایدبار در دسکتاپ، **نوار ناوبری پایین در موبایل**.
- نمودار قیمت با پرده گرادیانی، پنل دوئل با نشانگر زنده حریف، صفحه نتیجه با نمودار مقایسه سود دو طرف، حالت مساوی 🤝.

### 🐞 سایر باگ‌فیکس‌ها
- پایان روزهای بازی: اگه در روز آخر به هدف رسیده باشی، برد حساب می‌شه (قبلاً باخت!).
- سقف فرش برای بات‌ها (حداکثر ۵ در هر انبار) درست اعمال می‌شه.
- XSS-sanitize برای نام‌های کاربری که در HTML رندر می‌شن.
- debounce برای sync آنلاین (جلوگیری از رگبار درخواست).
- فونت/اعداد/جداول/مودال‌ها در RTL و سایزهای کوچک اصلاح شدن.

##  اجرا و نصب

```bash
# ساده‌ترین راه — سرو استاتیک:
python3 -m http.server 8080
# بعد مرورگر: http://localhost:8080
```

برای نصب به‌عنوان اپ: روی HTTPS (یا localhost) دکمه «📲 نصب» یا منوی مرورگر → Install.

هاست پیشنهادی: GitHub Pages / Netlify / Vercel (استاتیک، بدون بیلد).

## 🗂️ ساختار

```
index.html               اپ کامل بازی (HTML/CSS/JS)
manifest.webmanifest     متادیتای PWA
sw.js                    سرویس‌ورکر (کش پوسته + آفلاین)
icons/                   آیکون‌های اپ
vendor/supabase.js       کلاینت Supabase (نسخه vendor شده)
vendor/fonts/            فونت وزیرمتن (woff2)
supabase/functions/      سورس Edge Functions (match-next-day, match-join)
supabase/migrations/     مایگریشن‌های دیتابیس
```

## 🔐 یادداشت امنیتی
احراز هویت با Edge Functionهای سفارشی (username/password + bcrypt) است و توابع با `verify_jwt=false` deploy شدن؛ کلاینت با anon key صحبت می‌کنه. برای محیط production جدی، توصیه می‌شه RLS سخت‌گیرانه‌تر و توکن نشست اضافه بشه.
